## 🚨 UNANIMOUS CONSENSUS (all 3 models agree — highest confidence)

- Phone is the primary relapse vector → handing it 13x/day to film is "handing an alcoholic a shot glass"
- The reels project feeds the exact addiction that killed V1, V2-first, and V2-restart
- **Fix:** Delete Instagram, stop filming, block the app on all devices. No "documenting the journey."

### 2. SLEEP IS BROKEN — FIX IT BEFORE ANYTHING ELSE
- 3h21m on Day 1 night is not an anomaly — it's CNS collapse from overtraining + undereating + sleep restriction
- 04:45 tahajjud wake-up on 3h sleep is biologically delusional
- ADHD sleep latency (30-60 min) means 22:00 bedtime = 22:45 actual sleep = 6h, not 6h45m
- **Fix:** Push wake-up to 05:00-05:30. Cut tahajjud for Weeks 1-2 (the Master Blueprint already says this, but the Daily Blueprint contradicts it). Sleep 22:00→05:00 = 7h.

- Willpower is depleted by 18:15 after MMA + office — can't rely on it
- **Fix:** No couch before Maghrib. Walk in → wudu → active task (meal prep, stretching, reading) → Maghrib → immediately into study block. "The couch is lava."

### 4. TECH STACK IS MASSIVELY OVERSCOPED

- Ramish is still looking up HashMap/HashSet syntax
- **Fix:** Kill microservices, K8s, pgvector, CQRS, Saga. Build ONE clean monolithic Spring Boot API with PostgreSQL + basic Kafka. That's enough for 16 LPA.

### 5. DON'T APPLY TO JOBS UNTIL WEEK 6-7
- Applying in Week 3 with 0 DSA solved and a half-baked CRUD = burning recruiter bridges
- BFSI GCCs use HackerRank screens with LeetCode Medium/Hard — Ramish will fail and get blacklisted for 6 months

### 6. THE "60-DAY NOTICE" LIE IS DANGEROUS
- TCS BaNCS strictly enforces 90-day notice (billing dependencies)
- If an offer is extended based on 60 days and TCS refuses → offer rescinded
- **Fix:** State 90 days honestly. Target GCCs that plan quarters ahead — they'll wait for strong candidates.

### 7. RESUME FRAMING BORDERS ON FRAUD
- Claiming "Led microservices development" when his role was low-code is a trap
- A senior interviewer will dismantle this in 5 minutes on concurrency/transaction isolation
- **Fix:** Frame BaNCS as domain expertise + business logic, not distributed systems leadership. Put modern microservices under the personal project section.

### 8. TRACKING SYSTEM IS OVER-ENGINEERED
- 7+ markdown files with "Banked Days," "Help Flags," "state-machine" rules = cognitive overload
- This is "advanced ADHD procrastination disguised as productivity" (GLM-5.2)
