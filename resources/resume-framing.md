- "Worked on BaNCS RSM module using QPP"

## ✅ Write

### Experience Bullets

- "Led microservices development for Regulatory Server Module (RSM) in TCS BaNCS core banking platform, handling regulatory reporting workflows for capital markets clients"
- "Designed and implemented Market Info microservice for real-time market data ingestion and distribution across trading systems"
- "Built Limits enforcement service for pre-trade risk limit checking, including gross/net exposure limits and position limits"
- "Led development of microservices using Spring Boot, REST APIs, and QPP (Quick Process Portfolio) low-code platform for accelerated delivery"
- "Collaborated with Kafka and orchestration teams for event-driven communication between banking microservices"
- "Owned end-to-end delivery of [X] modules from requirements to production deployment for [banking client name if allowed]"
- "Reduced manual regulatory reporting effort by [X]% through automation of [specific workflow]"

- **Languages:** Java, SQL

## 🎯 Interview Answers

### "Why are you leaving TCS?"
"I'm looking for deeper engineering work. At TCS, my role involved significant low-code development on the BaNCS platform. I want to build production Java systems with modern architecture — microservices, Kafka, Kubernetes, AI integration. I've spent the last 3 months upskilling and building a production-grade project to bridge that gap."

### "Tell me about your project."
"I built a 2-microservice Spring Boot application with an API Gateway, Eureka service discovery, circuit breaker, Kafka event streaming, PostgreSQL with pgvector for AI-powered semantic search, and a RAG (Retrieval Augmented Generation) endpoint that integrates LLMs for intelligent product descriptions. Everything is Dockerized, deployed to Kubernetes on DigitalOcean, with full CI/CD via GitHub Actions and observability through Prometheus and Grafana."

### "What's your banking domain experience?"
"I worked on TCS BaNCS, a core banking platform. Specifically, I led microservices development for the Regulatory Server Module (RSM), which handles regulatory reporting workflows. I also built the Market Info microservice for real-time market data ingestion, and the Limits enforcement service for pre-trade risk limit checking — including gross/net exposure limits and position limits. I understand the trade lifecycle, regulatory requirements, and risk management in capital markets."
