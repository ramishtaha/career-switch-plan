## 3. SALAH: exactly what "with sunnah" means (Hanafi)

| Prayer | Before fard | After fard |
|---|---|---|
| **Fajr** | **2 sunnah** | — |
| **Dhuhr** | **4 sunnah** | **2 sunnah** |
| **Asr** | *(4, optional bonus)* | — |
| **Maghrib** | — | **2 sunnah** |
| **Isha** | *(4, optional bonus)* | **2 sunnah** → **Witr 3** |
| **Jumu'ah** (Fri) | **4 sunnah** | **4 sunnah** |

- **Witr = 3 rakat, one salam, du'a al-qunut in the 3rd before ruku.** It's wajib.
- **Winter Arc rule: Witr goes right after Isha, every night.** No decision, and no risk of a missed wajib if you sleep through.
- **Tahajjud** is valued but it's **not** part of the floor. If you're up 20 min before Fajr, pray 2–4 rakat. Witr has already been prayed, so don't repeat it. That's fine.
- **Duha** (2 rakat, after sunrise +20 min): bonus, slot is in the morning shape.
- **Missed a fard or Witr?** Make it up (qada) at the next chance you get, then carry on. One line in the ledger. That's all.

> *Plan-v3 said "Witr 1". In Hanafi fiqh Witr is 3. That's fixed here.*

## 9. WHEN A DAY GOES WRONG

**A missed item is a logged row, not a collapse.** Nothing resets. **There is no "Winter Arc 2."**

| Situation | What happens |
|---|---|
| **Missed any item** | Log it `M` + one reason. Tomorrow is a normal day. **No catch-up**, no doubling up |
| **Same item missed 2 days running** | Hermes asks one question: *"What blocked it?"* The fix waits for the Sunday review |
| **Slept late (past 22:30)** | No tahajjud. Wake for Fajr as normal. Floor as normal. **Lights out 21:00 tonight** |
| **Frozen / can't start** | Text Hermes **"frozen"**. You get one 10-minute task. Starting counts |
| **Overslept suhoor** | If you've had nothing since Fajr, **make niyyah before midday** (Hanafi allows it for a nafl fast). The fast still stands |
| **Sick** | Don't fast (log `M-sick`). **Run → 10-min walk.** Study what you can, log real minutes. Salah always, sitting if needed |
| **Broke a fast for health** | One make-up day later. No kaffarah. No guilt |
| **Guilt shows up** | Write: *"That was a missed rep, not a failed plan."* Then close the journal |

**The only real failure is a blank row.** A day you report as missed is still a day you reported.

*Fiqh points here are the standard Hanafi positions. For anything specific to you, ask a scholar. Hermes is a mentor, not a mufti.*
