# Ramish's Reels Guide — First-Time Creator

> **Guardrails (locked):** Separate account • No prayer footage • Documentary style
> **Posting:** From laptop browser ONLY • Instagram app STAYS BLOCKED on phone
> **Rule:** Reels = proof of work, never a replacement for the work

---

## Phase 1: Setup (One-time, 30 min)

### Instagram Account
1. Create a **new Instagram account** from laptop browser (instagram.com)
2. Username idea: `ramishbuilds` or `ramishcodes` or `ramish.switch`
3. Bio: `"TCS dev → Java/Spring Boot engineer. 12-week switch. Documenting the grind."`
4. Switch to **Professional Account** (Settings → Account → Professional)
5. **Do NOT install Instagram app on your phone** — it stays blocked

### Equipment
- **Phone**: Your personal phone (for filming only, 5-6 days, then get a second device)
- **Tripod**: ₹200-300 phone tripod from Amazon/Flipkart (optional but steady shots)
- **Lighting**: Window light is fine. Face the window, not away from it.

---

## Phase 2: Filming (10-15 min per reel)

### The 3-Format System

Pick ONE format per reel. Don't mix.

**Format A: "Today I Learned" (easiest, start here)**
- Hook (5 sec): *"Day 1. I just learned what a HashMap actually does."*
- Explain (20-30 sec): Talk to camera like explaining to a friend
- Close (5 sec): *"12-week career switch. Follow if you want to watch."*

**Format B: Screen Recording (for code)**
- Record your laptop screen with the code (use phone's screen record or OBS)
- Voice over: explain what the code does
- 30-60 seconds max

**Format C: Day-in-the-Life Montage**
- 3-5 short clips (5 sec each): desk, code, notebook, gym, mosque
- Text overlay: *"Day X of 84"*
- No voice needed — just lofi music or silence

### Filming Rules
- **Vertical only** (phone upright, 9:16)
- **Good lighting** > good camera
- **Audio**: quiet room, speak clearly, don't whisper
- **Length**: 15-60 seconds. Shorter = better for starting.
- **Retakes**: max 3 takes. Pick the best, move on. Perfection kills momentum.

---

## Phase 3: Editing (10-15 min max)

### Option 1: In-Phone (Simplest)
- Use phone's built-in editor (trim start/end)
- Add text overlay with the "Text" tool
- No fancy transitions. Raw = authentic.

### Option 2: CapCut (Free, more control)
- Download CapCut on phone
- Trim dead air
- Add auto-captions (helps silent viewers)
- Add one text overlay for the hook
- **Do NOT spend more than 15 min editing.** Set a timer.

### Editing Rules
- **Trim the first 2 seconds** (you always pause before speaking)
- **Captions ON** — 70% of people watch reels muted
- **No transitions** between clips — cuts only
- **One text overlay** max — your hook sentence

---

## Phase 4: Posting (5 min, laptop only)

1. Open **instagram.com** on laptop browser
2. Click **+ Create → Reel**
3. Upload your video file (transfer from phone via WhatsApp/Google Drive/USB)
4. **Caption format:**
   ```
   Day X/84 | 12-Week Career Switch

   [One line about what you did today]

   [One line about what you learned]

   #javadeveloper #careerSwitch #DSA #springboot #softwareengineer
   ```
5. **Cover**: pick a frame from the video where you're mid-sentence (looks more natural)
6. Post. Close the tab. Done.

## Phase 5: Content Calendar (what to film each week)

### Week 1-2: Foundation
- Day 1: "I'm switching from TCS to Java engineer in 12 weeks"
- Day 2-5: One DSA concept per reel (HashMap, Two Pointers, etc.)
- Weekend: "Week 1 recap — what went right, what went wrong"

### Week 3-4: Spring Boot
- "What is Spring Boot? (I had no idea either)"
- Show your IntelliJ screen with first Spring Boot app
- "Dependency Injection explained in 30 seconds"

### Week 5-6: Project Build
- Screen record building your project
- "Here's what my Spring Boot API does"
- Show Postman hitting your endpoint

### Week 7+ : Interview Prep
- "Mock interview question I failed today"
- System design whiteboard
- "How I'm preparing for BFSI interviews"

---

## Golden Rules (read before every reel)

1. **Bar first, reel after** — hit your DSA + career bar, THEN film
2. **20 min time-box** — film + edit + post in 20 min. Set a timer.
3. **Ugly > nothing** — a bad reel posted beats a perfect reel never posted
4. **No prayer footage** — guardrail, non-negotiable
5. **No sensitive info** — no TCS project names, no client data, no internal tools
6. **Post from laptop** — Instagram app stays blocked on phone
7. **Don't read comments for 24 hours** after posting. Post and walk away.
8. **Consistency > quality** — 5 ugly reels > 1 polished reel. Momentum builds.
